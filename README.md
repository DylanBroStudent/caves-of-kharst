# Caves of Kharst
This repo contains the game "Caves of Kharst" a multiplayer, dungeon delving, extraction puzzler, driven by a database, built for my DAT602 school assessment.

The report folder contains ongoing development milestones describing the planning, and ongoing development.

To play the game: 
1. first set up a MySQL server and run the CavesOfKharstDatabase.sql script to initialise the database
2. once initialised, run the client software and go through the process of creating an account, creating a character, and playing as the character.
3. You will be placed in a lobby where you may invite other characters to join you on your delve.
4. ready up and wait for the caves to generate
5. retrieve magical gems for points

NOTE as this is a development build, security principles are lacking. Please do not enter any personal information or reuse any real passwords.
